Lumen AIOps Platform — API Referansı

Bu sayfa Lumen platformunun tüm REST API endpoint'lerini belgeler. Tüm istekler JSON döner ve JWT Bearer token kimlik doğrulaması gerektirir (login hariç).

Base URL /api/v1 Format JSON Auth JWT Bearer Versiyon v1.0 Alpha
🔐 Kimlik Doğrulama

Login endpoint'i dışında tüm API isteklerinde Authorization header'ı gereklidir:

// İstek header'ı Authorization: Bearer <jwt_token> // JavaScript örneği fetch('/api/v1/anomalies', { headers: { 'Authorization': `Bearer ${localStorage.getItem('lumen_token')}`, 'Content-Type': 'application/json' } })

Token süresi dolduğunda 401 Unauthorized döner. Yeni token için POST /api/v1/auth/login kullanın.
